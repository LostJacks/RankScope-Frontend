# RankScope Frontend

This repository contains the React frontend for RankScope.

RankScope is a League of Legends Machine Learning project that predicts which competitive rank a player's performance in a selected ranked match most closely resembles.

## Features

- Enter Riot ID and region
- Retrieve recent Ranked Solo/Duo matches
- Choose one of the five most recent matches
- Send the selected match to the RankScope backend
- Display the predicted performance rank
- About and How It Works pages

## Technologies

- React
- Vite
- JavaScript
- CSS
